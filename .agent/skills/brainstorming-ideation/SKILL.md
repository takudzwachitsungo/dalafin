# Brainstorming & Feature Ideation Framework

## 1. Core Objectives
- Uncover high-impact behavioral intervention features that help users curb impulse spending and reach financial goals.
- Evaluate technical feasibility vs. user delight before writing code.

## 2. Ideation Principles
- **Behavioral Psychology First**: Focus on friction points (e.g. forced cool-offs, opportunity cost visualization, reward streaks).
- **SCAMPER Framework**:
  - **S**ubstitute: Replace plain numbers with relatable physical items (e.g. $100 = 20 coffees).
  - **C**ombine: Merge daily reflections with AI sentiment analysis.
  - **A**dapt: Adapt gamification mechanics (streaks, badges, celebration confetti) to money management.
  - **M**odify: Dynamic cooldowns based on item category or price.
  - **P**ut to another use: Turn impulse logs into learning journals.
  - **E**liminate: Remove friction from logging income/expenses while adding deliberate friction to high-risk spending.
  - **R**everse: Instead of budgeting forward, auto-roll over unused daily caps backward.

## 3. Decision Matrix
Evaluate every idea on a 1-5 scale across:
1. **User Behavioral Impact** (Will this stop impulse buys?)
2. **Implementation Complexity** (Hours of dev time required)
3. **Delight & Visual Polish** (Does it wow the user?)
